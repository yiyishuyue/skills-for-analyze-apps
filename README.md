# 产品人实用 Skill 库

给产品人、独立开发者使用的 Agent Skills：从用户问题中找线索，判断下一步值不值得投入，再用真实交易数据验证怎样收费。目前有三个使用分工、四份独立技能包，用户调研skills同时保留 X 原版与跨平台升级版。

**调研社媒上用户真实吐槽点；决定值不值得继续投入，用金融模型辅助决策；判断怎样收费能让收入更高，数据基建支撑定价分析。**

## 我现在该用哪个？

| 你正在问的问题 | 使用哪个 Skill | 你需要提供什么 | 它会交付什么 |
|---|---|---|---|
| 想研究多个社媒平台上的真实观点，或自动取数失败但有截图/文本？ | [Social Feedback Research](skills/social-feedback-research/SKILL.md) | 研究问题、目标人群与平台；可带现成材料 | 能力检查、采样路径、正负观点与分歧、来源证据、行动建议 |
| X 上的用户在说什么？为什么抱怨、卸载或换竞品？有什么值得借鉴？ | [X 用户反馈与竞品洞察](skills/x-feedback-insights/SKILL.md) | 产品/品类、竞品、平台与时间范围；已有语料也可 | 可追溯用户原话、反馈簇、证据强弱、迁移路径、P0–P3 动作 |
| 直接开发、先验证还是暂停？哪个方案值得投入？ | [Decision Model Coach](skills/decision-model-coach/SKILL.md) | 当前选择、目标、约束及已有证据；可以不知道成本或概率 | 有条件的行动建议、主要取舍、验证方案；输入充分时做定量模型 |
| 已有产品，该涨价还是降价？低价续费更好是否值得？ | [Pricing Revenue Coach](skills/pricing-revenue-coach/SKILL.md) | 当前收费方式、想改变什么，以及现有价格/曝光/订单/续费数据；没对照数据也可 | 价格实验方案，或需求响应、首购及累计收入比较、候选价与补测建议 |

这些技能可以单独使用，也可以按问题串联。没有竞品研究需求，可以直接做投入决策；已有合格价格数据，可以直接做定价分析。

### 用户调研的两份版本怎么选？

- `x-feedback-insights`：保留现有 X 专项原版，偏重吐槽、流失路径与竞品借鉴，继续适用于已接好原取数接口的工作方式。
- `social-feedback-research`：从原版复制后独立升级，面向跨平台观点调研；先试采，再选择接口、浏览器或人工材料路径。新用户及跨 Agent 使用优先选这份。

两份目录均自包含，可单独安装。跨平台升级版不承诺所有平台都能自动抓取；小红书等若无法读取，会交付具体采样计划并接收截图、文本或导出材料。没有原始证据时只交付计划，不生成观点报告。平台覆盖需逐次验证，正文与评论分别说明。

### 定价 Skill 会先带你判断入口

不知道能不能用时，直接描述情况，它会先确认三个问题：

1. **现在已经有人付费了吗？**
2. **想改变的是价格，还是收费方式、权益和套餐？**
3. **有对照数据，还是需要先设计测试？**

没有付费用户不等于不能用：已有稳定使用证据、准备首次收费时，可以设计收费验证。只有想法或自用原型时，先弄清外部需求，暂时不估算“收入最高的价格”。

没有实验数据时，交付的是测试方案；有合格数据后，才进一步比较收入和价格。按次改订阅、加年包、改权益属于方案变化，需要分析整体影响。

## 串联使用skills示范案例：把一个 AI 学习助手从想法推进到收费

以下是使用过程示例，所有情景均为假设，不代表已开展调研或获得真实实验结果。

### 第一步：找问题/痛点——社媒用户观点调研

你有一个 AI 学习助手想法，但不知道现有产品的哪种体验值得改善。

可以这样问：

> 使用 social-feedback-research，研究近90天 X 和小红书上几个 AI 学习类产品的用户看法。先检查能否读取正文和评论，保留正负意见与反例。某平台抓不到时给我具体采样步骤，我可以补截图；按平台整理原话、来源、分歧和借鉴动作。

它应交付可追溯的证据包。如果没有足够相关讨论，应指出平台或研究范围的限制，提出其他取证方式，不把沉默解释为没有需求。

**交给下一步的材料：**原话及来源、具体使用场景、证据强度、尚未确定的假设。投诉不能直接代表全部用户，也不能直接证明他们愿意为新产品付费。

### 第二步：定行动——决策建模

有了线索后，你仍在比较“完整开发、用现有原型做验证、暂缓”。

可以这样问：

> 使用 decision-model-coach，结合这份证据包，帮我比较直接开发、先做外部验证和暂缓。我自己借助AI开发，成本还没拆清，希望一个月内获得用户反馈。先识别最影响决策的信息缺口。

它应澄清“一个月有反馈”与“一个月回本”的区别，核对原型、招募途径和资源约束。若证据不足，应设计可执行的验证，而非编造成功率或未来利润；已有充分证据时也可建议直接推进。

**交给下一步的材料：**已验证的目标场景、独立使用与复用证据、当前产品权益、成本和预算约束。计划完成不等于需求已验证；未获得足够证据时继续本阶段，而非为了流程完整强行进入定价。

### 第三步：定收费——定价分析

假设产品后来已经有人实际使用并付费，你开始比较同一月包的不同价格。

可以这样问：

> 使用 pricing-revenue-coach。产品已有付费用户，月包权益保持不变，想测试几个不同价格。目前没有价格对照数据，请先检查候选价依据，再设计分组、记录字段、转化窗口和停止规则。

取得数据后继续：

> 这是各价格组的合格曝光人数、固定窗口付费人数、实收和退款记录；订阅还附各期到期及成功收款数据。请比较每位分组用户的首购与累计收入，区分已测最佳价格和拟合候选价。

它应先核对流量和队列可比性，再比较收入。有需要时拟合需求；数据不足则给候选范围或补测，不承诺一定求出唯一最优价。后续加年包时，还要计算它替代了多少月包收入。

**再回到决策建模：**如果测试显示收入不足以覆盖新增投入，可以带着定价证据重新比较调整产品、改变投入或暂停。三个技能帮助形成持续复盘，而非一次性流水线。

## 怎么开始使用

选择需要的技能，将对应的整个目录放入所用 Agent 工具支持的技能目录，保留其中的 references/、templates/ 等子目录。不同工具的安装位置和加载方式以该工具说明为准。

也可以把对应 SKILL.md 及其引用文件交给支持读取文件的 Agent，明确要求按该流程执行；仅上传文件不保证工具已自动安装或加载技能。

| 目录 | 版本/状态 |
|---|---|
| [skills/social-feedback-research/](skills/social-feedback-research/) | V1.0.0，跨平台升级副本，含取数与人工采样指南 |
| [skills/x-feedback-insights/](skills/x-feedback-insights/) | 原版 X 反馈抓取与洞察技能及报告模板 |
| [skills/decision-model-coach/](skills/decision-model-coach/) | V1.4.1，含可选 Python 计算后端与真实项目模型回放 |
| [skills/pricing-revenue-coach/](skills/pricing-revenue-coach/) | V1.2.0，含三问入口 |

这些技能以分析工作流为主。Decision Model Coach V1.4.1 另附 Python 标准库计算后端，支持平面方案、单层概率情景和显式敏感性扫描，无需 WorkBuddy 账号或在线服务。运行时需保留整个技能目录，并允许执行 Python；仅有聊天能力时不能声称运行了程序。其他技能按任务需要使用 Agent 的联网、计算、图表或数据连接能力，缺少能力时应说明并调整交付范围。

X 反馈分析保留现有 Grok Bot 来源版本，X 取数接口名及 /workspace/ 路径可能需要适配当前环境。跨平台副本按当前环境发现工具和输出路径；没有可用接口时不能声称已抓取。加载技能不会自动安装其他技能或连接外部服务。

## 能力与验证边界

- 决策建模 V1.4.1：33 项程序回归、6 项兼容检查与 21 项真实项目模型回放检查通过，附 [管道工程概率树与敏感性案例](skills/decision-model-coach/examples/pipeline-risk/case-report.md)、输入和复跑材料。案例检验了单层概率树回溯、五方案成本排序、推荐反转边界及指定错误检测；概率来自项目专家评估，不是观测频率。它不证明递归多阶段树、输入概率真实性或真实用户前瞻效果，详见 [验证记录](skills/decision-model-coach/references/validation-status.md)。
- 定价分析已做公式算例检查及一例 ZipRecruiter 公开汇总数据回放，能比较转化与收入的取舍；未完整复现其用户级估计和订阅累计收款，也未证明适用于所有产品。
- X 反馈分析依赖可获得语料及来源核验，社交初筛不替代代表性用户研究或产品实测。
- 跨平台副本已做结构与流程审阅，未完成各平台真实采集验证；附带的验收场景不是平台可用性证明。
- 所有技能均应区分事实、推导、假设和未知，给出局限以及会改变建议的新证据。实际改价、招募或发布实验需要用户授权。

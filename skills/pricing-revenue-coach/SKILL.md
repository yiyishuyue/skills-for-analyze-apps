# Pricing Revenue Coach
## 定价与收入优化教练

帮助用户先用自己的价格实验认识需求，再选择收入更高的价格。用户描述业务并提供可获得的数据，Agent 负责澄清口径、检验实验、计算、解释和提出下一步。

## 目标与边界

默认目标是指定用户群、流量基数和观察期内的总收入最大化。“卖得最好”在本技能中指收入表现，不等于销量或转化率最高；有歧义先澄清。

区分首购收入、含续费的累计收入、每位付费用户收入 LTV、每位进入实验用户收入，以及扣除成本后的利润。默认不把收入目标改成利润目标；可另列成本和退款风险。

适用：已有可售产品、权益相同或可控制的单档价格选择。尚未证明需求的产品可先做需求验证；不要把低转化直接解释为定价错误。

课程主线按四层推进：**单 SKU 首购 → 订阅累计收入 → 月年包组合 → 分群定价**。识别用户当前问题并在该层交付，不要求每个任务四层全做完。分析组合 SKU 时先承认选择间的替代关系，不能沿用单 SKU 固定销量的结论。

具体模型及课堂示例的适用条件见 [references/course-workflow.md](references/course-workflow.md)。进入续费候选筛选、年包或分群问题时阅读对应部分。

## 入口：先回答三个简单问题

用户不知道何时使用本技能时，先用日常语言问下面三个问题；从已有上下文能确定的直接复述确认，不重复提问，也不一开始索要整张数据表。

1. **现在已经有人付费了吗？** 如果还没有，是已经有稳定外部使用、准备首次收费，还是只有想法/自用原型？这决定当前应验证需求还是验证价格。
2. **你想改变的是价格，还是收费方式、权益和套餐？** 例如同一个月包从20元改成30元，属于价格点；按次改订阅、加年包或升级权益，则是方案/组合变化。
3. **你有对照数据，还是需要先设计测试？** 可以先回答“有几个价格的曝光与订单”“只有历史销售记录”或“还没有数据”；之后再针对缺口取数。

根据答案立即给出“你现在在哪一步 → 这次能得到什么 → 还缺什么 → 下一步”：

| 当前状态 | 本次交付与去向 |
|---|---|
| 只有想法/自用原型，尚无外部需求证据 | 说明目前不能估最佳价，帮助定义需求验证；若环境有 decision-model-coach，可建议用它判断下一步投入。本技能仍可澄清未来收费假设，不要求先安装另一个技能 |
| 已有可售产品或稳定使用证据，准备首次收费，但尚无人付费 | 设计首次真实收费验证；用户表达愿付不等于实际付款，价格与需求仍需共同验证 |
| 已有付费，想调整同一SKU价格，没有合格对照数据 | 设计价格实验，给记录字段与统一观察窗；没有数据也可使用 |
| 同一SKU且有可比数据 | 进入收入比较、需求响应与按需拟合 |
| 要改变按次/订阅、权益或月年包组合 | 比较完整方案，记录被替代销量和整体收入，不能把两个数字当作纯价格点 |
| 只有历史前后销售记录 | 做有限的描述性诊断，指出混杂并提出补测；不宣称因果或唯一最优价 |

例如用户说“月包已有付费用户，想比较9、19、29元，还没测试”，可以回答：“你现在适合做价格实验设计。这轮先明确分组、要记录的数据和何时比较收入，还不能给出最佳价。”

需求调研、投入决策、价格验证可以按需要切换；社交投诉不是愿付或价格弹性数据，不把三个技能当成固定必经流程。

## 1. 先澄清，再计算

从上下文提取：产品与目标用户、单次购买或订阅、币种、价格周期、当前价、候选价、主要收入指标、观察期、流量渠道、试用和折扣、变动成本约束。

每轮只问最影响判断的 1～3 个问题，说明为什么需要、从哪里取数、没有时怎么处理。不要先让用户选择曲线公式。

优先收集：

| 字段 | 用途 |
|---|---|
| 价格组、实际成交价、币种和计费周期 | 避免标价与实收、月价与年价混用 |
| 每组进入实验的合格去重用户数 | 固定比较分母，含未购买用户 |
| 首次曝光/分组日期、分配比例和随机化单位 | 判断流量、队列和实验质量 |
| 固定转化窗口内的首次付费人数、订单数、实收金额 | 区分人数、件数、转化与收入 |
| 产品版本、渠道、地区、试用和促销规则 | 判断是否只有价格不同 |
| 退款金额及统一截止日 | 明确毛实收或扣退款后的收入口径 |
| 订阅每期到期人数、成功续费人数、收费金额和时间 | 处理续费机会和观察成熟度 |

若只有转化率，继续索取分母和窗口；若只有购买量，索取流量。可先给描述性比较，但不得据此宣称价格造成差异。
数据不足时列缺口、可判断范围和实验方案；不编造需求曲线、续费率或最优价。

## 2. 数据可比性闸门

计算前阅读 [references/measurement-models.md](references/measurement-models.md)，核对曝光、窗口、公式与模型条件。首先确认对照的是同一 SKU：相同权益、周期、试用条件，只改变价格。组合 SKU 则转入组合方案实验。

- 优先同时期随机分组、用户固定分组，避免同一用户反复见到不同价格；说明分组单位和污染风险。
- 检查预设分流与实际样本比例是否异常、埋点是否缺失、组间用户构成是否失衡；重大异常先排查。
- 产品、权益、试用、付费文案或投放若同步改变，不能将整体变化归因于价格。
- 历史前后比较需考虑渠道、季节、竞品和产品变化，标记为观察性证据。
- 转化窗口以首次分组或曝光为起点统一计算。尚未走完整个窗口的用户不与成熟队列混比；各组使用相同入组日期范围。
- 免费试用开始、试用转付费和首次实际收款分开。续费按相同订阅年龄比较，尚未到期不算未续费。
- 稳定的不只是流量总数，还有渠道、用户构成及购买意图；自然流量可作为起点，但不天然无偏，付费流量也不自动失效。投放策略变化导致人群漂移时，应分层、控制实验或暂停跨期拟合。
- 流量不必完全相等，但来源和构成应可比较；按每位分组用户收入或统一曝光基数归一化。归一化不能修复混杂或不完整窗口。
- 确认口径后锁定主指标、观察期和停止规则，避免看见短暂领先就停止。

结论分级：仅能设计实验 / 描述性比较 / 有条件的模型估计 / 经新实验确认的候选价。不要将四个点等同于充分样本或因果证明。

## 3. 没有合格数据时，设计价格实验

围绕当前价及有依据的可接受价格区间设置彼此拉开的候选点。例如可从四个价格组开始，具体点位依据现价、历史成交、用户研究、商业约束和可用样本决定，不将“四组”作为通用最低统计标准。

保留当前价对照。流量不足时减少组数或分阶段探索；价格差异需有学习价值且在可承受风险内，不能为画图盲目大幅涨跌。

交付：目标用户、价格组及依据、随机化与分配比例、主指标、业务上值得检测的最小差异、基线及所需样本估算方法、转化/续费观察窗、产品冻结项、护栏、停止条件和下一轮动作。缺少基线时先小规模校准，不承诺固定天数足够。

首购主指标通常为每位合格分组用户首购收入；订阅长期主指标为固定期限每位分组用户累计收入。将转化、退款、投诉、每期留存与服务成本作为解释或护栏指标。

只交付方案，不因加载技能而自行改价、发布实验或收费。

## 4. 先比较观测点，再描述需求

计算每组的购买转化、实际收入和统一曝光下收入。展示样本量与不确定性；有用户级数据时可按随机化单位重抽样收入差，涉及多次查看、多组选择时解释选择偏差并按设计校正或独立复验。

数据仅支持“测试价格中观测收入最高”的结论时，明确这样表述，不能升级为“真正最优价”。

绘图优先：
1. 价格—购买转化/归一化购买量散点，标清样本量、窗口和不确定性。
2. 价格—每位曝光用户收入，区分观测点与拟合线。
3. 订阅另画价格—相同期限累计收入及按订阅年龄的续费/留存曲线。

传统需求图用横轴数量、纵轴价格；若改用横轴价格，也必须标清，不能直接凭视觉坡度判定弹性。

解释曲线的水平、局部斜率和弹性；这些取决于坐标尺度与用户群，不能从“健康产品”“工具产品”等行业标签预设曲线。实验反映给定条件下的成交响应，不是逐个用户真实最高支付意愿的直接测量。

## 5. 有依据时拟合、求候选价

少量点先用观测比较；需要拟合时选择简单、符合数据与业务范围的模型，检查残差、预测有效范围和不同模型下推荐是否稳定。不要用四点高阶插值强行制造顶点，或仅凭 R² 选模型。

按课程思路先解释 P、Q、TR，再用实测数据选择线性或非线性需求。参考文件包含线性、课程对数需求 Q(P)=α ln(β/P)、指数和常弹性模型；不把任一函数称为所有产品的“真正需求曲线”。

在线性逆需求 P=a−bQ 下，写出 TR=aQ−bQ²、MR=dTR/dQ=a−2bQ，再检查最大点。课程对数需求用 dTR/dP 求价格驻点；它与 MR=dTR/dQ 不同，需注明求导变量。求驻点后仍需检查二阶条件、可行区间、端点和平台可售价格档。

只在已有支持范围内给候选价，范围外优先追加实验。最优点落在边界、曲线模型差异很大或收入差无法区分时，给候选区间和补测建议，不给虚假的小数点精确价格。

## 6. 订阅同时比较获客与续费

在每个价格的首购转化之外，计算同一观察期限的每位付费用户累计收入，再乘首购转化率或直接用分组总收入除以全部分组用户数。

用户级分组收入是选价格的主要比较口径；只比较已付费者 LTV 会遗漏价格筛选了谁、多少人购买。
优先用成熟队列实测，不同订阅年龄不混比。第一期续费率不能直接外推终身，续费价格是否锁定也需确认。

以首购最优候选为基准，检验更低价格带来的新增成交与留存能否补偿首购收入损失；不要只挑两组收入相近的点来代表全部候选。对于首购收入很接近且留存差异不足以改变排名的候选，可减少追加试验；“价格接近”不等于留存相同，须有数据或敏感性界限支持。

更低价格可能降低首购收入但提高后续收入，也可能没有帮助。课程“高价侧可以排除”的启发仅在已确认的支配关系成立时使用；不因线性抛物线示意而删除所有高价组。具体筛选与反转阈值见课程参考。
长期模型只能作为带假设的情景，实际观察收入与预测尾部分列；说明期限、折现、留存和不确定性。

## 7. 弹性与失败诊断

局部弹性描述数量对价格百分比变化的响应，不等于图上斜率；按参考文件计算并说明可比性及误差。

降价后转化低，依次检查：数据/流量、转化窗口、试用与购买环节、产品价值和信任、替代品、价格测试是否跨过可能敏感区间。
不能从两个低转化点推出没有市场、需求整段没弹性，或必须继续砍价。当前证据不足时提出能区分这些解释的补测。

## 8. 月年包组合与分群扩展

识别用户是否已经进入多 SKU 决策：固定月价后，可以测试不同年价，但此时月包购买量也会变化。收入比较必须覆盖全部分组用户，观察月转年、原本不买的人转化、服务期与未来续费变化。不能把原来月包收入与新增年包收入机械相加。

年包候选参考月包的预计累计贡献与 12 个月标价，但不是把两者之间任意价格都当作净增。按课程参考中的组合需求与迁移模型比较同期限收入/现金流，权益和呈现变化需记录。

分群定价先确认同商品不同人群价格与不同权益套餐的区别。消费者剩余表示理论支付意愿空间，不等于保证可获得的增收；需要可解释、可实施的人群与实际实验依据。仅在当前业务需要时推进，不自动按年龄、健康或敏感属性制定价格。

## 9. 输出与复盘

按 [templates/report-outline.md](templates/report-outline.md) 交付，按实际数据删去不适用模块。至少回答：
- 当前用户群的需求响应呈现什么形状，哪些地方还未知。
- 首购收入最高的已测价格；模型候选最优价单列并注明条件。
- 订阅累计收入最优价格是否不同，还是续费数据未成熟、尚不能回答；给出低价反超需要的留存/收费次数提升阈值。
- 若涉及多 SKU 或分群，报告整体收入、替代迁移和适用人群，不能把单档最佳价宣称为组合最优。
- 推荐执行、保留现价或追加测试的理由、风险、观察期限。
- 什么新证据会改变推荐，以及下一步如何调整。

若有图表工具生成图；否则交付清晰数据表和坐标定义，不声称已生成图。保留数据来源、计算公式、模型参数、实验局限和待确认假设，用户可追溯复算。

## 10. 质量检查

- 目标为收入还是销量/利润已明确，首购与续费口径分开。
- 组间可比；曝光分母、固定转化窗、续费机会和退款截止一致。
- 观测最佳、拟合候选和确认实验结论区分。
- 未编造续费、最高支付意愿、成功概率或市场案例数据。
- 拟合没有任意外推、负需求、强制顶点或斜率冒充弹性。
- 不确定性、反转条件和下一轮实验具体。
- 对数需求与常弹性模型区分；MR 和对价格求导区分。
- 续费支配筛选有证据；年包扣除被替代月包收入，分群不把消费者剩余当保证增收。
- 演示算例、计算校验和真实业务验证分别报告。

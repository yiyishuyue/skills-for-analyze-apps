# 取数与人工采样指南

## 能力检查

先发现实际连接和工具，再检查目标平台、内容层级。不根据插件名称推断已可采集。没有适用连接时可搜索可用插件；连接、登录和实际试采分别报告。不要求用户把密码或会话凭证贴进聊天。

试采记录：`平台 | 路径/工具 | 查询与时间窗 | 搜索可读 | 正文可读 | 评论可读 | 日期/来源可定位 | 限制 | 下一步`。

- X：Grok Bot、xAI 搜索、平台 API 和网页搜索是不同路径，其他 Agent 不自动继承 Grok Bot 的能力。工具字段、配额及计费以当前连接说明为准。
- 小红书等：试读实际笔记及评论。存在开放接口不等于支持全站笔记/评论搜索；失败时不承诺换 Agent 就一定能抓到。
- 其他社区：按实际接口、可读页面或材料处理，不预先宣称支持。

只有摘要时保留为待核验线索，原文不可访问就说明。其他平台内容不冒充目标平台证据。遵守实际访问要求，不绕过访问控制。

## 人工采样交接包

自动路径失败后先给具体计划：
1. 研究问题、关键词及别名，包含中性、正向、负向与行为词。
2. 时间窗、搜索排序、计划看多少结果、每篇怎样选择评论。数量根据目的和用户时间约定，标为计划。
3. 按约定顺序连续采样，记录未入选及原因。仅采热门结果要注明热度偏差；补近期结果时分开记录。
4. 保存链接或平台 ID、正文、相关评论与父级上下文、日期、采集时间、排序和折叠状态。无链接则保存截图文件名及图中位置。
5. 保留反例与无法归类的材料，避免只挑符合预期的案例；不采集无关个人信息。

收到后检查能否区分独立帖文/账号、原话是否清楚、评论属于哪篇帖文。缺字段标未知；局部缺失可先分析并缩小结论。OCR 后核对原图，不能核对的文字不作确定性引语。

## 停止条件

达到约定时间/样本预算时停止，说明覆盖。相同障碍经一次诊断性替代尝试仍存在则停该路径，给出替代。连续无新主题可作为本次停止参考，不宣称总体观点已穷尽。无有效原文时只交付取数状态和采样计划。

## 验收场景（行为检查，不代表平台实测）

| 输入条件 | 应有行为 |
|---|---|
| X 搜索可用，回复不可读 | 分析帖文并说明未覆盖评论 |
| 小红书登录/验证码阻断 | 停止反复重试，转用户登录或人工采样 |
| 只有搜索摘要 | 单列线索，不伪装成原文引用 |
| 截图观点互相矛盾 | 定位原话、保留分歧、标缺失上下文 |
| 同帖跨平台搬运 | 保留来源关系，不算独立重复验证 |
| 找不到讨论 | 区分覆盖不足和低声量，不判定无需求 |
